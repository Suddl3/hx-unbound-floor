## Screen mirror repairs

- Include the previously missing generated `m4/floor_mirror.bin` so an opted-in build
  works from a clean source checkout. It is assembled patch code, not extracted Line 6
  firmware. The assembly retains its HXtra attribution.
- Preserve eight-byte stack alignment when calling the firmware from the command handler.
- Check all ten bytes of the two replayed calls and prologue before writing the trampoline.
- Bound assembler/objcopy subprocesses to 60 seconds each, assemble into temporary files,
  verify symbol offsets before writing output, and provide `--check` for reproducibility.
- Validate host reply dimensions, row bitmap and payload length; invalidate stale image
  state on failures and limit resynchronization to two requests.

Two independent assemblies using Zig 0.15.2 produced the same 1,716-byte payload and
unchanged symbol map. Payload SHA-256:
`8a55bab3eadc15fd00bb5f235f046010dde4a79f7725c21216541b654f6cb73f`.

The mirror stays **off by default**. Its row hashes can collide, and a live framebuffer
can change during capture; this is a diagnostic screen view, not an exact atomic snapshot.
The amended handler still needs a deliberate hardware validation before being called
hardware-verified. Do not run the host mirror alongside HX Edit.

## Headroom runner repairs

- Put hardware CLI execution behind guarded entrypoints; importing the headroom modules
  does not connect USB or start audio/tests.
- Stop on failed preset readback, tone-command errors, incomplete/failed soaks or timeouts.
- Always request `soak_eb.py --stop-on-freeze` from the headroom runner; it cannot silently
  use that script's historical automatic power recovery. Standalone soak behavior is
  unchanged unless that explicit flag is supplied, and is documented.
- Bound tone commands to 120 seconds and soaks to the requested duration plus 300 seconds.
- Document that these deliberate hardware tests discard the current unsaved edit buffer.

Readback verifies model lists, not every parameter; tone metrics require human review.
The **default NAM DSP cost remains 3600**. The author's cost-3250 results apply to the
PAIR layout; the integration does not lower the default or certify arbitrary block counts.

## Offline verification

On the integrated tree, with Python, pytest, NumPy, Capstone and Unicorn in an isolated
review environment:

```text
pytest -q -m "not slow and not firmware" tests helix-floor/floor/test_screen_mirror_host.py
139 passed, 1 skipped, 5 deselected

python helix-floor/floor/test_screen_mirror.py
ALL PASS
```

The 139 include 25 headroom mock tests and 18 mirror host/build tests. Hardware-dependent
headroom imports/calls are replaced with fakes; no real USB or audio operation runs.
The emulator checks registration, full and changed-row replies, resync, invalid addresses,
yielding, and stack alignment at firmware calls. The skip requires `arm-none-eabi-gcc`.
Slow simulator tests and firmware-marked tests were not rerun in this integration pass.
Historical baseline results remain in [ROADMAP.md](ROADMAP.md).

Using the same existing private post-kernel input, the old `084d309` main-program
stage and integrated `e56f50b` stage with the mirror disabled produced byte-identical
92,711,516-byte outputs (SHA-256
`fe4a9c8b0110eb283fc4d88cfe29ca7ff367386ce5ce0e9ea3f44f7a562d28e9`).
With the mirror enabled, the stage also passed the actual stock-byte guards, cave
readback and unchanged-Entry-1 checks. This checks the changed main-program stage;
it is not a new full kernel build or a hardware test. Private inputs/outputs are
not included in the repository.

## Editor channel

[Suddl3/hx-edit-nam](https://github.com/Suddl3/hx-edit-nam/tree/floor) now defaults to its
maintained `floor` branch. It publishes the existing `f72e7af` Floor-library source plus
setup documentation (`c4757ca`); no navigation code or proprietary application is added.
The [pairing contract](EDITOR.md) distinguishes the normal ID 380 block from experimental
ID 555 variants and links the pinned installation instructions. New navigation Candidates
54–57 remain withdrawn. A packaged installer and exact-pair collaborator check are still ahead.

Upstream features will be reviewed selectively. No automatic upstream merge, polling
service or scheduled watcher was installed by this cleanup.
